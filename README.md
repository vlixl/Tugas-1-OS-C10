# Tugas-1-OS-C10

**Untuk menjalankan sisinfo.sh di Linux, jalankan perintah-perintah berikut:**

```bash
# Compile resource_check.c
gcc resource_check.c -o resource_check

# Buatlah script tersebut menjadi executable
chmod +x sysinfo.sh

# Jalankan script tersebut
./sysinfo.sh

# Tunjukkan isi laporan pada terminal
cat sysinfo_report.txt
```
